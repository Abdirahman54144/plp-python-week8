# PLP Python Week 8 Assignment - Final Project: Personal Mini-Toolkit

This repository contains the final capstone project for the Python course, bringing together variables, loops, conditionals, lists, user inputs, and robust error/menu handling into an interactive command-line application.

## Project Overview
The **Personal Mini-Toolkit** offers three distinct functional tools managed through a centralized, loop-driven menu system:
1. **Number Guessing Game**: Generates a random number and guides the user using conditional feedback loops.
2. **Todo List Manager**: Utilizes dynamic lists to add, view, and remove tasks safely.
3. **Temperature Converter**: Performs metric conversions between Celsius and Fahrenheit.

## How to Run
1. Make sure Python is installed on your system.
2. Open the project folder in your terminal or VS Code.
3. Run the application using the command:
   bash
   python toolkit.py

## Project Reflection
Working on this final capstone project was an exciting culmination of everything learned throughout the course. The hardest part was ensuring that user inputs across different sub-menus handled unexpected data types (like letters instead of numbers) without crashing the main application loop. Debugging the list index removal bounds in the Todo manager took careful iteration, but it greatly reinforced my understanding of list slicing and index tracking. If I had one more week, I would expand the toolkit to include a persistent data storage feature, writing notes and tasks directly to external text files.
